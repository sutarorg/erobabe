# Streamtape Migration — Historical Record

> **Status:** Retired. The Streamtape integration was removed in October 2026
> and replaced with direct MP4 URL publishing. This document is preserved as a
> historical record only.

## What Happened

1. **PR #20** replaced Uqload with UFOLOAD as the video hosting integration.
2. **PR #22** replaced UFOLOAD with Streamtape.
3. **This PR** removed Streamtape entirely and replaced all video upload methods
   with direct MP4 URL publishing.

## Current Architecture

Videos are now published by pasting direct MP4 URLs into the admin panel.
Erobabe saves the URL in `videos.playable_url` and the browser plays the video
straight from the original host. No video bytes are downloaded, transferred,
re-encoded, or stored by Erobabe.

- **Provider:** `direct_url`
- **Playback:** Native `<video>` element with `playable_url`
- **Thumbnail:** Uploaded to Supabase Storage (unchanged)
- **Metadata:** Generated by Gemini AI (unchanged)

## Legacy Videos

Existing videos from Streamtape, UFOLOAD, Uqload, and embed-only records are
**not affected**. Their stored `playable_url` and `embed_url` values are
preserved and the public player continues to render them correctly:

- Videos with `embed_url` use the iframe player (unchanged).
- Videos with `playable_url` use the native `<video>` player (unchanged).

No code contacts the retired provider APIs. The status route returns historical
records as-is.

## Removed Files

The following files were removed as part of this migration:

- `lib/video/streamtape.ts` — Streamtape API client
- `lib/video/streamtape-flow.ts` — Upload/import lifecycle
- `lib/video/streamtape-protocol.ts` — Protocol constants and parsers
- `lib/video/relay-token.ts` — Signed relay tokens
- `relay/streamtape-relay.mjs` — Upload relay server
- `app/api/videos/streamtape-session/route.ts` — Upload session endpoint
- `app/api/videos/streamtape-cancel/route.ts` — Upload cancellation endpoint
- `app/api/videos/upload/route.ts` — Upload completion endpoint

## Removed Environment Variables

The following environment variables are no longer needed:

- `STREAMTAPE_LOGIN`
- `STREAMTAPE_API_KEY`
- `STREAMTAPE_FOLDER_ID`
- `STREAMTAPE_ADULT_CONTENT_ALLOWED`
- `STREAMTAPE_MAX_UPLOAD_BYTES`
- `STREAMTAPE_MAX_ACTIVE_IMPORTS`
- `STREAMTAPE_UPLOAD_HOST_SUFFIXES`
- `STREAMTAPE_RELAY_URL`
- `STREAMTAPE_RELAY_SECRET`
- `VIDEO_PROVIDER` (defaults to `direct_url`)
